# 家電どう捨てる？（kaden-sutekata）

捨てたい家電と場面（買い替えるか・前に買った店があるか・自分で運べるか）を見て、正しい出し方を当てる1日5問の学習ゲーム。正解したら、どの決まり（家電リサイクル法の4品目・パソコンの回収・小型家電リサイクル法・似ているが外のもの）かも選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/kaden-sutekata/>

- 中身は、家電リサイクル法（特定家庭用機器再商品化法）の第9条・第17条と施行令第1条、小型家電リサイクル法の施行令第1条（e-Gov 法令検索で読んだ現行の条文）と、経済産業省「パソコンのリサイクル（資源有効利用促進法）」に書いてあることだけです。
- 問題の場面は練習のための例です。
- このゲームは公式の情報の代わりではありません。出す日・場所・料金は市区町村やお店・メーカーの案内で確かめ、決まりは法令で確かめてください。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。結果の画面で遊ぶ人が「Xで投稿」「LINEで送る」を押したときだけ、回の番号・日付と成績の印（問題・答えは入れない）がそのサービスに渡ります。

作業の決まりは [AGENTS.md](AGENTS.md)。
